# 🎨 UI Interativa com CSS + JavaScript

Projeto de interface interativa criado com HTML, CSS e JavaScript puro, inspirado nos desafios do site CSS BATTLE e em personagens da cultura Nerd.

Cada seção do projeto representa um componente visual animado, controlado por eventos e estados via JavaScript.

---

## 🚀 Funcionalidades

- Animações com CSS (@keyframes, transform, box-shadow)
- Interações com clique e teclado
- Controle de estados com JavaScript puro
- Componentes visuais independentes
- Criação dinâmica de elementos no DOM

---

## 🧠 Objetivo

Explorar o poder do CSS e do JavaScript puro na criação de interfaces interativas sem frameworks.

---

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
